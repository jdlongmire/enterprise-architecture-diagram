# Enterprise Architecture Diagram

Make editable PowerPoint diagrams (architecture overviews, capability maps, system context diagrams, swimlane process flows) in a clean pastel-card, line-icon style with live connectors.

You write a small JSON spec that describes the content. A script turns it into an editable PowerPoint file and tells you exactly what to fix. Start with `SKILL.md`; it is the entry point and walks the whole workflow: pick a template, fill it in, build, fix, deliver. Finished specs with preview images live in `examples/`, fill-in starting points in `templates/`, and the full field, icon, and report references in `reference/`.

Output formats: PPTX (the editable master), plus PDF, PNG, JPG, and SVG rendered from it.
